# Pulpit_menadzer

Mały skrypt w Pythonie do automatycznego sortowania plików na pulpicie.  

## Funkcje
- Tworzy foldery: `Pliki_tekstowe`, `Foldery`, `Programy`
- Przenosi pliki tekstowe (.txt, .pdf, .docx, .rtf) do `Pliki_tekstowe`
- Przenosi obrazy (.jpg) do folderu `Obrazy`
- Przenosi pliki wykonywalne (.exe) do `Programy`
- Przenosi pozostałe foldery do `Foldery`
